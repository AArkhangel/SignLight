## Инструкция по запуску и технические характеристики

## ТТХ и возможности

### Технологический стек
*  React 19 (Hooks: `useState`, `useEffect`, `useRef`).
*   Tailwind CSS 3.4 (Cyberpunk Design System).
*   `@mediapipe/tasks-vision` (Hand Landmarker).
*   `lucide-react` (векторные иконки).
*   Web Speech API (`window.speechSynthesis`).
*   Vite (высокая скорость HMR).

### Технические параметры (ТТХ)
*   ** Mediapipe HandLandmarker (Float16).
*  ** 21 ключевая точка на каждую руку.
*   ** руки 2 одновременно.
*   ** On-Device (полностью локально, без отправки данных в облако).
*   ** Использование GPU через WebGL/WASM.
*   **задержка пока пипец ~10-40 мс, зависима от мощности устройства.

### Возможности
1.  **Real-Time Hand Tracking**: Визуализация анатомического скелета кисти в реальном времени.
2.  **Smart Light (Адаптивная подсветка)**: Динамический анализ яркости кадра. При недостатке света экран автоматически становится "софтбоксом", освещая лицо и руки.
3.  **Simulated Gesture Recognition**: Алгоритм имитации перевода жестов в текст с 5%-ой вероятностью обновления на каждом кадре.
4.  **Auto-Voice Integration**: Автоматическая озвучка текста на русском языке с предотвращением наложения голосов.
5.  **Cyberpunk UI/UX**: Премиальный интерфейс с эффектами глитча, пульсации и телеметрии в реальном времени.

## запуск

### 1. Требования
*   **Node.js**: Версия 20.x или выше.
*   **Браузер**: Chrome, Edge или любой другой на базе Chromium (рекомендуется для стабильной работы MediaPipe).
*   **Веб-камера**: Необходима для работы системы трекинга.

### 2. Установка зависимостей
Открыть терминал в папке проекта и выполнить команду: 
```
npm install
```

### 3. Запуск сервера разработки
```
npm run dev
```

## 🛠 Руководство пользователя

### 1. Начало работы
При открытии страницы вы увидите заставку **"ЗАГРУЗКА ML МОДЕЛИ..."**. 
*   Система скачивает необходимые нейросетевые веса (`hand_landmarker.task`) из облака Google.
*   Как только кнопка внизу станет активной и надпись изменится на **"START SESSION"**, приложение готово.

### 2. Запуск сессии
Нажмите кнопку **START SESSION**. Браузер запросит разрешение на использование камеры. 
> **Важно:** Необходимо разрешить использование камеры, иначе движок не заработает

### 3. Интерфейс
После запуска вы увидите:
*   **Видео-центр**: Ваше зеркальное изображение с наложенным золотым скелетом руки.
*   **Telemetry (Верхний угол)**: 
    *   `FPS`: Скорость работы нейросети (цель по скорости работы — 30+ FPS).
    *   `LUX`: Текущий уровень освещенности в люксах .
*   **Status Indicators**: Индикаторы активного GPU и режима записи ( recorder )

### 4. Функция Smart Light
Если в комнате станет слишком темно, SignLight автоматически:
1.  Определит падение уровня освещенности в люксах.
2.  Увеличит `EXPOSURE COMP` в углу экрана.
3.  Экран вашего устройства начнет работать как софтбокс, освещая руки для лучшего распознавания.
4.  Цель 1 - создать аналогичную подсветку для губ для лучшего опыта общения на РЖЯ
5.  Цель 2 - расширение базы данных по жестам для перевода в автопереводчике
6.  Цель 3 - создание аналогичного приложения для перевода речи в жесты

### 5. Перевод и Озвучка
*   **Перевод**: Когда камера видит ваши руки, система симулирует перевод. беря сравнивая известные ей жесты из базы данных, при совпадении на 90% текст появляется в блоке снизу.
*   **Auto-Voice**: По умолчанию озвучка включена. Каждое новое слово будет произноситься синтезатором речи (ru-RU) (только русский язык)
* В планах после РЖЯ сделать базу данных ASL для распознавания американского жестового языка.

*   **Кнопки управления**:
    *   `VOLUME ICON`: Нажмите, чтобы повторить последнюю фразу.
    *   `ON/OFF`: Переключатель режима автоматической озвучки.

## Параметры и описание

| **Pipeline FPS** | Скорость обработки кадров нейросетью | 24 - 60 |
| **Light Level (Lux)** | Средняя яркость сцены (0-255) | > 100 |
| **Smart Intensity** | Процент яркости экранной подсветки | 0% (день) / 100% (ночь) |

## Решение проблем

*   **Черный экран**: Убедитесь, что камера не используется другим приложением (Zoom, Skype и т.д.).
*   **Низкий FPS**: Проверьте, что в браузере включено аппаратное ускорение (Hardware Acceleration).
*   **Нет звука**: Убедитесь, что в системе установлены русские голоса для TTS.
*   **Модель не грузится**: Проверьте соединение с интернетом (требуется для первого запуска).

## Запуск на мобильном устройстве (в локальной сети)

Для тестирования на мобильном устройстве ( телефон/ планшет) необходимо:
1.  **Общий доступ**: Оба устройства (ПК и телефон/ планшет ) должны быть в одной Wi-Fi сети.
2.  **Запуск с флагом Host**:
    Выполните команду:
    ```bash
    npm run dev -- --host
    ```
3.  **IP-адрес**: В терминале появится адрес вида `http://192.168.x.x:5173`.
4.  **Важное ограничение (HTTPS)**: 
    Браузеры блокируют камеру на сайтах без HTTPS (кроме `localhost`). Чтобы камера заработала на телефоне через локальный IP:
    *   **Вариант А**: Используйте сервис **ngrok** или **localtunnel** для получения временного HTTPS-адреса.
    *   **Вариант Б (для Chrome)**: Зайдите на телефоне в `chrome://flags/#unsafely-treat-insecure-origin-as-secure`, добавьте ваш IP-адрес в список и перезагрузите браузер.
