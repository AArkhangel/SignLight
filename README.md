# React + Vite

Данный шаблон содержит минимальную настройку для работы React в Vite с HRM и некоторыми правилами ESLint
В настоящее время доступны 2 официальных плагина:
- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) использующий [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) использующий [SWC](https://swc.rs/)

## React Compiler

Компилятор React не включён в этом шаблоне из-за его влияния на производительность разработки и сборки [this documentation](https://react.dev/learn/react-compiler/installation).
